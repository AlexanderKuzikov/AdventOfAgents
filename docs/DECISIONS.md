# ADR

Append-only. Новое решение — новая запись внизу.

## 001. Субтитры в json3, а не vtt

**Контекст.** YouTube отдаёт автосубтитры в двух форматах. В VTT реплики приходят
«катящимися» окнами с перекрывающимся текстом: соседние блоки дублируют конец
предыдущего. В json3 каждое событие — одна уникальная реплика.

**Решение.** Качать `--sub-format json3`, парсить события.

**Следствие.** Дедупликация сводится к сравнению с предыдущей репликой — одна строка.
С VTT пришлось бы разбирать окна по таймкодам начала. `techdebt`: json3 — не
документированный формат, при смене разметки YouTube парсер придётся править.

## 002. Перевод живёт в translation.json, метаданные — в page.json

**Контекст.** API сезона отдаёт заголовок, теги, ссылки и код; страница `.md` даёт
длительность и автора видео. Держать всё в одном файле означало бы каждый раз
затирать ручной перевод при перезакачке.

**Решение.** `page.json` и `translation.json` — разные файлы, `build.py` их сливает.
`translation.json` хранит и `en`, и `ru`: английский нужен в левой колонке HTML
и в приложении с исправлениями.

**Следствие.** Перевод переживает обновление данных сайта. `build.py` падает, если
хотя бы один сегмент без `ru` — защита от молчаливых пропусков.

## 003. Сезон в пути, а не плоский dayNN

**Контекст.** Season 2 и Season 3 оба имеют day01.

**Решение.** `data/s3-2026-10/day01`.

**Следствие.** Ключ дня — путь `s3-2026-10/day01`, имена файлов в `dist/` длиннее.
Зато коллизий нет и сезон виден без открывания файла.

## 004. Проверка доступности видео через oEmbed перед yt-dlp

**Контекст.** Часть архивных роликов (15 из 54) закрыта или удалена. Каждый вызов
yt-dlp на таком видео — это полная попытка разобрать плеер впустую, единицы на видео.

**Решение.** Перед `yt-dlp` один запрос `youtube.com/oembed`. 404 — видео недоступно,
идём дальше.

**Следствие.** Полная подготовка сайта (60 дней) укладывается в разумное время.

## 005. Двуязычный HTML — таблица с колонками, а не два документа

**Контекст.** Пользователь просил «точное противопоставление абзацев»: английский
абзац должен стоять ровно напротив своего перевода.

**Решение.** CSS grid, три колонки: таймкод, EN, RU. Каждая строка — один сегмент,
высота строки = максимум из двух колонок. Таймкод печатается только на первой строке
блока, продолжения помечены штрихом — иначе колонка таймкодов превращается в шум.

**Следствие.** Строки не выравниваются по высоте текста, но всегда по границе сегмента.
Это и нужно: противопоставление по смыслу, а не по числу строк.
