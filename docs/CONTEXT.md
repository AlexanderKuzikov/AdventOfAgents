## Что работает

- `prepare.py --all` — страницы, субтитры, черновики. Идемпотентен, переведённые дни не трогает.
- `enrich.py` — дозабирает длительность, название и автора ролика (в архивных сезонах
  их нет в `.md`-страницах).
- `context.py` — контекст дня (описание, ссылки, код) вместе с сегментами. Основа перевода:
  код со страницы снимает все догадки об именах.
- `build.py` — сайт: индекс с фильтром по тегам и материалами, страницы дней в обвязке
  (шапка, хлебные крошки, переключение колонок, печать, пагинация по сезону), DOCX.
  Падает на неполном переводе и на битом JSON.
- `assets.py` — общий стиль и скрипты сайта.
- `check_links.py` — все локальные ссылки в `dist/`; 455 ссылок, 0 битых.
- `check_docx.py` — проверка docx без Word.
- `catalog.py` — `docs/CATALOG.md`, 60 дней с тегами, ссылками и кодом.
