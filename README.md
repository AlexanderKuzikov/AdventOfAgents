# Advent of Agents — перевод видео на русский

Двуязычные транскрипции роликов Google Cloud [Advent of Agents](https://adventofagents.com):
английский оригинал слева, русский перевод справа, с точным противопоставлением абзацев.

Источник: сайт отдаёт всё в markdown (`Accept: text/markdown` или суффикс `.md`),
манифест сезонов лежит в `/.well-known/mcp.json`. Субтитры — авто-распознавание
YouTube (`en-orig`), перевод восстанавливается по смыслу, спорные места помечены.

## Что внутри

```
data/<сезон>/<день>/
  page.md            исходная страница сайта
  page.json          метаданные: заголовок, теги, ссылки, код, видео
  en-orig.json3      автосубтитры YouTube
  draft.json         сегменты с пустым "ru" — черновик для перевода
  translation.json   сегменты с переводом (то, что собирается в dist/)
dist/<сезон>/<день>/
  ...-en-ru.html     двуязычная страница: EN | RU, скрытие колонок, подсветка правок
  ...-transcript-ru.docx   перевод одним потоком + приложение с исправлениями
docs/CATALOG.md      все 60 дней: теги, ссылки, код, статусы перевода
```

Три сезона: **s1-2025-12** (25 дней), **s2-2026-03** (31), **s3-2026-10** (опубликовано 4 из 31).
Субтитры есть у 38 дней, переведены пока s3 — первые четыре.

## Конвейер

```bash
python scripts/registry.py              # сезоны и счётчики
python scripts/prepare.py --all         # скачать страницы и субтитры
python scripts/prepare.py s3-2026-10 day05    # один день
python scripts/catalog.py               # пересобрать docs/CATALOG.md
python scripts/build.py                 # собрать dist/ из переводов
python scripts/build.py s3-2026-10/day04      # один день
python scripts/show.py s3-2026-10/day04       # показать сегменты
```

Зависимости: Python 3.11+, `yt-dlp`, `python-docx`. Больше ничего — только стандартная библиотека.

## Как перевести новый день

1. `python scripts/prepare.py <сезон> dayNN` — скачает страницу, субтитры и `draft.json`.
2. Открыть `draft.json`, заполнить `ru` (по одному абзацу на осмысленную фразу) →
   сохранить как `translation.json`.
3. Где распознавание явно соврало — заполнить `fix`: одна строка «что было → что стало».
4. `python scripts/build.py <сезон>/dayNN` и `python scripts/catalog.py`.

`build.py` не пропустит день с пустым переводом — это защита от молчаливых пропусков.

## Перевод

Термины оставляем в оригинале (ADK, Agent Gateway, Model Armor, scope, rogue action,
Cloud Run), переводим остальное. Таймкоды — из автосубтитров, они иногда не совпадают
с речью на пару секунд, это нормально.
