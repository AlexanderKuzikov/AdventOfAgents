# AGENTS.md

## Что это

Перевод роликов Advent of Agents на русский. Данные — в `data/`, генераторы — в
`scripts/`, артефакты — в `dist/`. Ничего не коммитить и не пушить без явной просьбы.

## Конвейер — три скрипта

| Скрипт | Что делает | Когда |
|---|---|---|
| `registry.py` | сезоны, дни, счётчики из `/.well-known/mcp.json` | посмотреть, что вообще есть |
| `prepare.py` | страница `.md` + субтитры + `draft.json` | новый день или обновление данных |
| `catalog.py` | `docs/CATALOG.md` из всех `page.json` | после появления новых дней |
| `build.py` | `dist/` из `translation.json` | после перевода |
| `show.py` | сегменты дня на stdout | перед переводом |
| `check_docx.py` | проверка docx без Word: шрифт, кегль, таймкоды, таблица правок | после сборки |

## Структура данных

`data/<сезон>/<день>/`, сезон — `s<N>-<год>-<месяц>`, день — `dayNN`.

- `page.md` — страница сайта как есть, не правим.
- `page.json` — производное от API сезона и `.md`-страницы. Правки в нём теряются
  при повторном `prepare.py`; править источник.
- `en-orig.json3` — автосубтитры. Не трогаем.
- `draft.json` — черновик, перезаписывается. Его роль — дать английский текст
  по сегментам для перевода.
- `translation.json` — **единственный ручной артефакт**. Хранит и английский, и
  русский: английский нужен в двуязычной колонке и в приложении с правками.

## Правила перевода

1. Один сегмент — один осмысленный абзац, а не одна реплика. Реплики склеиваются
   по смыслу: `prepare.py` даёт черновик, переводчик перегруппировывает руками.
2. Термины GCP/ADK не переводим: ADK, Agent Gateway, Agent Registry, Model Armor,
   Agent Runtime, Cloud Run, GKE, SPIFFE, scope, rogue action, eval, trace, prompt injection.
3. Там, где автосубтитры дали осмысленную, но неверную формулировку — заполнить
   `fix`: «что распознано → что имелось в виду». Это попадает в приложение к
   HTML и DOCX, поэтому пользователь видит, где переводчик вмешался.
4. Имена людей и продуктов восстанавливать по `page.json` (`creator_name`,
   `video_title`), а не по догадкам.
5. Не выдумывать то, чего нет в аудио. Фрагмент огрызок — перевести огрызок
   и отметить в `fix`.

## Проверка перед сдачей

```bash
python scripts/build.py <сезон>/dayNN     # сам не пропустит пустой перевод
python scripts/check_docx.py              # шрифт, кегль, таймкоды, таблица правок
```

Word COM (`preview.mjs`) нужен для визуального рендера, но он зависает, если в
системе остались зависшие процессы Word. Проверяй так:

```powershell
Get-Process WINWORD | Select Id, StartTime      # нет ли зависших
Get-Process WINWORD | Stop-Process -Force       # свои процессы можно снять
```

Зависший рендер оставляет рядом с docx файл `~$...docx` — не коммитить, `check_docx.py`
их пропускает.

Сгенерированный docx/html не отдаётся пользователю без проверки: в коде не видно ни
съехавшей таблицы, ни обрезанного текста. HTML смотрится через локальный сервер:

```bash
python -m http.server 8742     # затем http://127.0.0.1:8742/dist/<...>
```

## Границы

- `data/_registry/` — кэш сайта (манифест и API сезонов). Обновляется флагом
  `--refresh`, коммитится.
- `dist/` — генерируется из `translation.json`, коммитится только для переведённых дней.
- Не качать `llms-full.txt`: он дублирует содержимое, которое уже лежит в `data/`.
